# 📖 使用指南 — 像聊天一样处理文件

> 无需学习编程，用日常说话的方式让 AI 帮你操作文件。

---

## 🎯 这是什么？

你是否有过这些烦恼？

- 想把一堆 JPG 转成 PNG，但不想一个一个手动改
- 想从 100 页的 PDF 里提取第 3-5 页的内容
- 想看看视频的分辨率和时长，但不知道怎么查
- 想解压一个 RAR 文件，但电脑没装 WinRAR

**这个项目就是解决这些问题的。** 把它装好之后，你只需要在聊天框里用大白话说出需求，AI 就会自动帮你完成。

---

## 🗣️ 怎么用？（核心原理）

```
你说：「帮我把 D:\照片\旅游 文件夹里的所有 PNG 图片转成 JPG」
        ↓
AI 理解你的需求 → 自动选择合适的工具 → 执行 → 返回结果
```

你不用管具体是哪个工具、参数是什么——AI 会自己判断。

## 🚀 三步上手

### 第 1 步：确认装好了

打开 Cherry Studio（或你用的其他客户端），在聊天框输入：

```
你能看到哪些 MCP 工具？
```

如果 AI 回复了类似「pdf_read、word_read、image_info、archive_list…」等工具名称，说明安装成功 ✅

如果没有任何工具，请回到 [INSTALL.md](INSTALL.md) 检查配置。

### 第 2 步：试一个最简单的

```
查看 D:\test.txt 的信息
```

（前提：D 盘确实有一个 test.txt 文件）

### 第 3 步：开始日常使用

以后需要处理文件时，像跟同事说话一样描述需求就行。AI 会自己选择合适的工具。

## 💡 进阶技巧

### 技巧 1：一次做多件事

```
先看看 report.pdf 有多少页，然后把前 3 页的内容提取出来
```

AI 会自动分步调用工具。

### 技巧 2：批量操作

```
把 D:\photos 文件夹里所有 PNG 图片转成 JPG
```

AI 会先列出文件，再逐个转换。

### 技巧 3：组合文件类型

```
读取 sales.xlsx 的 Sheet1 数据，根据数据写一份 Word 周报
```

AI 会先调 Excel 读取工具，再调 Word 写入工具。

### 技巧 4：指定精确参数

如果默认结果不理想，你可以直接说参数：

```
把 photo.png 转成 JPG，质量设为 95

把 video.mp4 转成 avi，用 H.264 编码
```

## ❓ 常见问题

### Q：我说话 AI 不理我？

**A：**试试说 `查看 D:\test.txt 的信息`（确保文件存在）。如果仍然不响应，检查 MCP 是否启用。

### Q：AI 说「找不到工具」？

**A：**MCP Server 没有正确连接。重启 Cherry Studio，到设置 → MCP 确认 6 个服务器都是绿色/已连接状态。

### Q：处理大文件很慢？

**A：**正常。PDF 100 页、视频转码等操作本来就需要时间。如果卡住超过 2 分钟，可能是参数太大（比如 PDF 一次读太多页），试试缩小范围。

### Q：OCR 识别不了中文？

**A：**安装 Tesseract 时需要勾选中文语言包（Chinese Simplified）。参见 [INSTALL.md](INSTALL.md)。

### Q：视频处理报错？

**A：**大概率是没装 FFmpeg。安装方法见 [INSTALL.md](INSTALL.md) Step 2。

### Q：我的文件路径有空格怎么办？

**A：**用引号包起来即可：`查看 "D:\My Documents\report.pdf" 的信息`
